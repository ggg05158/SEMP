# SEMP

**System Equipment Management Program** — 체계 장비 이력관리 프로그램.

Python + PySide6로 구현한 데스크톱 첫 버전입니다. 장비 트리, 일련번호별 실물, 날짜별 서식 메모, 공통 그룹 기록, 해시태그와 엑셀 등록을 지원합니다.

## 실행

현재 작업 컴퓨터에는 프로젝트 `.venv`에 실행 환경을 설치했습니다. **`SEMP.py`를 더블클릭**하면 콘솔 창 없이 실행됩니다. `start.cmd`는 사용하지 않아도 됩니다.

다른 PC에서는 Python 3.11 이상을 설치하고 `install.cmd`를 한 번 실행한 다음 `SEMP.py`를 더블클릭합니다. 첫 라이브러리 설치에는 인터넷이 필요하며, 설치 후 프로그램 사용은 오프라인으로 가능합니다. `.venv`는 컴퓨터별로 새로 만들고 복사하지 않습니다. Windows에서 `.py` 파일 연결 프로그램이 Python으로 설정되어 있어야 합니다.

터미널 실행:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe SEMP.py
```

`SEMP.py` 뒤에 `project.semp` 경로를 지정하면 해당 프로젝트를 엽니다. 실행 파일(EXE) 패키징은 아직 포함하지 않았습니다.

## 처음 사용하기

1. 초기 화면의 **프로젝트 파일 불러오기**에서 기존 `project.semp` 파일을 선택합니다. 처음 사용할 때는 **새 프로젝트**에서 저장할 상위 폴더와 이름을 선택합니다.
2. **＋ 그룹**으로 자유롭게 분류를 만들고 **＋ 장치**로 장치 종류를 등록합니다. 그룹은 여러 단계로 중첩할 수 있습니다.
3. 장치를 선택하고 **＋ 일련번호**에서 처음/끝, 용도와 설명을 입력합니다. 끝을 비우면 한 개만 생성합니다. 설명은 상위 장치 설명을 초깃값으로 제안하며 따로 수정할 수 있습니다.
4. 상단의 **기록 작성**을 누르고 작성창 오른쪽에서 대상 그룹·장치·개별 장비를 체크합니다. 사용·위치·출고·입고·이슈·기타, 종류 버튼, 날짜, 현 위치(선택), 본문과 태그를 입력합니다. 제목은 따로 입력하지 않으며 목록에서는 종류를 크게 표시하고 그 아래에 본문을 한 번만 보여줍니다. **＋ 추가**로 종류를 입력하면 저장 시 프로젝트의 종류 목록에 함께 추가됩니다.
5. **기본 정보** 탭 또는 F2에서 이름, 설명, 해시태그를 편집합니다. 그룹·장치는 설명을 입력하며, 일련번호가 있는 개별 장비는 용도와 설명을 각각 입력합니다. 용도는 **비행용 · 예비용 · 환경용 · 점검용** 버튼에서 선택합니다. **＋ 추가**로 새 용도를 입력할 수 있으며, 저장한 용도는 다음 등록·수정 창에서도 버튼으로 표시됩니다. 개별 장비 상세 화면의 **용도** 값을 더블클릭하면 바로 수정할 수 있습니다. 여러 장비를 한 번에 바꾸려면 **기록 작성 → 용도변경**을 선택하고 대상 장비와 변경할 용도를 지정합니다. 기록 저장과 동시에 선택한 장비의 용도가 바뀝니다. 기존에 저장된 용도와 설명을 서로 변환하지 않습니다.
   사용자 추가 용도는 버튼을 마우스 오른쪽으로 눌러 후보 목록에서 삭제할 수 있습니다. 기본 네 가지 용도와 이미 장비에 저장된 값은 바뀌지 않습니다.
6. 기록 내용과 선택한 대상은 함께 저장됩니다. 수정창에서도 대상을 바꿀 수 있고, 저장된 기록에 트리 항목을 드래그하거나 **선택 장비 연결**로 추가할 수도 있습니다. 그룹·장치 등록 및 수정창의 Enter는 저장, Esc는 취소입니다.

새 프로젝트에는 **탑재장치 · 점검장비 · 케이블 · 기타** 기본 그룹만 생성됩니다. 기존 프로젝트를 열 때는 그룹을 추가하지 않습니다.

- 초기 화면과 **프로젝트 → 최근 프로젝트**에는 최근 경로 8개를 표시합니다. 초기 화면은 프로젝트 이름을 굵게, 경로를 작은 글씨로 나누어 보여줍니다. 이 경로는 현재 PC의 앱 설정에만 저장되며, 찾을 수 없는 파일은 비활성화됩니다.
- **SEMP 로고** 또는 **프로젝트 이름**을 누르면 달력 메인 화면으로 돌아갑니다.
- **전체 장비** 화면은 큰 달력을 표시합니다. 기존 장비별 기록을 포함해 기록이 있는 날짜에는 작은 숫자 배지로 건수를 표시합니다. 여러 장비에 연결된 하나의 기록은 한 건으로 집계합니다. 날짜를 클릭하면 그날의 기록 목록을 보여주며, 없으면 **기록 없음**을 표시합니다. 목록 아래 **날짜별 기록 작성** 버튼으로 해당 날짜의 기록을 만듭니다. 아래 기록을 더블클릭하면 별도 탭에서 상세 내용을 확인하고 **기록 수정**으로 편집합니다.
- 기록은 시작일·종료일을 직접 입력하거나 각각의 **달력 아이콘**으로 선택합니다. 시작일과 종료일을 포함한 전체 기간에 달력 건수가 표시되며, 기존 기록은 하루짜리 기록으로 유지됩니다. 종료일이 지나도 장비의 마지막 위치·상태를 자동으로 지우지는 않습니다.
- 달력과 기록 목록에는 **장치 이름 · 일련번호 외 N개** 형식으로 연결 대상을 표시합니다.
- 장치 선택과 기록 열기는 브라우저처럼 탭을 추가합니다. 같은 대상을 다시 열면 기존 탭으로 이동하고, 탭의 ×로 닫습니다. 탭 줄 오른쪽의 **모든 탭 닫기**는 홈만 남기고 장치·검색·기록 탭을 한 번에 닫습니다. 로고·프로젝트 이름과 왼쪽의 **달력 보기**는 홈의 전체 기록 달력으로 돌아갑니다.
- 기록 저장 후에는 현재 화면을 유지합니다. 통합 검색에서 연 기록 탭의 목록은 해당 검색어에 맞는 기록만 보여주며, 달력·장비 이력에서 연 상세 탭은 별도 기록 목록을 표시하지 않습니다.
- 트리를 선택한 상태에서 **Ctrl+Z**로 소속 이동을 취소하고 **Ctrl+Y**로 다시 실행합니다. 여러 항목을 함께 옮긴 작업도 한 번에 되돌립니다. 새 이동을 하면 재실행 목록을 비우고, 프로젝트를 닫으면 이동 기록도 비웁니다. 이름 충돌이나 삭제로 복원이 불가능하면 작업을 적용하지 않고 알려줍니다.
- 현 위치와 해시태그 입력창 아래에는 최근 사용한 값을 최대 5개 추천합니다. 클릭하면 입력되며, 최근 순서는 기록을 저장할 때 갱신됩니다.
- 글자색과 강조색은 색 계열별 팔레트에서 선택하며, 색상 코드 직접 입력과 미리보기도 지원합니다. 글자색은 진한 두 단계, 강조색은 옅은 세 단계로 구분했습니다. 배열은 [Atlassian 색상 선택 가이드](https://atlassian.design/foundations/color/color-picker-swatches)를 참고했습니다.
- 트리는 일련번호만 표시합니다. 개별 장비 상세 화면은 상위 장치 이름을 배지로 표시하고 옆에 일련번호를 보여줍니다. 예: **[GCU] A001**.
- 트리에서 그룹·장치를 우클릭하여 **복제**하거나 **Ctrl+D**를 누르면 하위 항목과 기본 정보를 함께 복제합니다. 같은 위치에서 이름을 **장치 (1)**, **장치 (2)** 순으로 붙입니다. 기존 기록 연결과 장비 모음 소속은 복제하지 않습니다.
- 장비 상세 화면에서 **기록 작성**을 누를 때만 트리의 선택 장비를 미리 체크합니다. 달력, 통합 검색, 기록 조회 화면에서 작성할 때는 대상을 직접 선택합니다. 기록 목록은 달력과 장비의 활동 이력에서 확인할 수 있습니다.
- 해시태그는 공백을 입력하면 칩으로 묶입니다. 칩의 **×**로 삭제할 수 있고, 마지막 공백을 입력하지 않은 태그도 저장됩니다.
- 상단 **장비 모음**에서 여러 그룹에 있는 장비를 선택해 모음을 생성·수정·삭제합니다. 기록 작성창 오른쪽에서 모음을 골라 **모음 장비 선택**을 누르면 모음의 장비를 아래 기록 대상에 한 번에 체크합니다. 원래 장비의 소속은 유지되며, 모음에는 저장할 때 선택한 개별 장비가 들어갑니다. 이후 새로 등록한 장비는 모음 수정에서 추가하세요. 모음을 바꾸거나 삭제해도 이미 저장된 기록의 대상은 유지됩니다.
- 장비 모음 목록과 선택 드롭다운은 항목이 많아지면 자동으로 스크롤됩니다. 장비 모음 만들기와 기록 작성의 대상 선택창은 트리를 왼쪽에 길게 표시하고 필터·모음 조작은 오른쪽에 배치합니다.

- 왼쪽 트리는 이름·일련번호 검색, 용도와 일련번호 순번으로 필터링합니다. 장비 모음과 기록 작성의 오른쪽 필터는 용도·순번·구분 버튼을 여러 개 동시에 선택할 수 있습니다. 같은 종류 안에서는 합집합, 서로 다른 종류 사이는 교집합으로 적용하며 버튼에는 해당 장비 수를 표시합니다. 순번을 판정할 때 연도는 위치와 관계없이 제외하고 뒷부분의 장비 번호를 사용합니다. 따라서 `2024-A001`, `A001-2025`, `T-26001`, `T-25001`은 모두 1번째입니다. 순번 숫자가 전혀 없는 일련번호만 자연 정렬 위치를 사용합니다. 1~3번째 외의 순번은 직접 추가할 수 있습니다. **필터 결과 선택**은 현재 조건에 맞는 대상만 추가하며, 다른 조건에서 선택해 둔 장비는 유지됩니다.

## 이력과 상태의 규칙

- 일련번호는 같은 장치 아래에서 중복될 수 없습니다. 다른 장치 아래에서는 같은 일련번호를 사용할 수 있습니다.
- 그룹과 장치에도 기록을 작성할 수 있습니다. 개별 항목의 **상위 그룹 이력 포함**을 켜면 현재 상위 항목들의 기록이 함께 보이며 출처를 표시합니다.
- 트리에서 장비를 이동하면 공통 이력의 조회 범위는 **현재 트리 구조**를 따릅니다. 과거 소속을 별도 스냅샷으로 저장하는 기능은 아직 없습니다.
- 기록에 그룹을 넣으면 **연결 당시의 하위 개별 장비**를 중복 없이 연결합니다. 일련번호가 없는 장치는 장치 자체를 연결합니다. 나중에 생성한 하위 장비는 기존 기록에 자동 추가되지 않습니다.
- 장비의 현재 위치는 **오늘까지의 직접 기록 또는 연결 기록** 중 위치가 입력된 가장 최근 기록으로 계산합니다. 상태는 같은 범위에서 최근 사용·출고·입고 기록을 따릅니다. 같은 날짜에는 생성 순서가 늦은 기록을 우선합니다.
- 상위 그룹 기록은 하위 장비의 현재 위치나 상태를 바꾸지 않습니다. 여러 장비의 상태를 함께 반영하려면 기록에 실제 대상 장비를 연결하세요.
- 일반 검색은 이름·일련번호·메모·위치 등을 검색합니다. `#현장A`는 정확한 태그를 검색하며 `#현장A #시험`은 두 태그를 모두 가진 결과를 찾습니다. 장비에 붙은 태그로 그 장비의 직접 이력도 검색할 수 있습니다.
- 메모는 굵게·기울임·밑줄·크기·글자색·강조색을 선택 영역에 적용할 수 있습니다. 이 버전의 메모는 텍스트와 서식을 지원하며 이미지/파일 첨부는 지원하지 않습니다.

## 엑셀 대량 등록

프로그램의 **도구 → 엑셀 템플릿 저장**을 사용합니다. 템플릿은 `SEMP.py`가 직접 생성하므로 별도의 템플릿 폴더나 XLSX 파일을 함께 가져갈 필요가 없습니다. 입력 열은 장치이름·일련번호 처음·일련번호 끝·용도·위치·설명·태그이며, 오른쪽 안내 영역은 자동 등록되지 않습니다.

| 장치이름 | 일련번호 처음 | 일련번호 끝 | 용도 | 위치 | 설명 | 태그 |
|---|---|---|---|---|---|---|
| 장치A | 2501 |  | 실전용 | 격납고 A | 00할 때 쓰는 장비 | #주력 #비행 |
|  | 2502 |  | 실전용 | 격납고 A | ㅁㅁ할 때 쓰는 장비 | #주력 |
| 케이블 D |  |  |  | 자재실 | 신호 케이블 | #케이블 |

- `.xlsx` 형식을 지원합니다. 첫 행의 열 이름을 변경하지 마세요. 확장 열이 없는 기존 3열·4열 파일도 지원합니다. 읽을 시트는 `장비등록`, 없으면 첫 번째 시트입니다.
- 용도는 **비행용 · 예비용 · 환경용 · 점검용** 또는 원하는 값을 직접 입력합니다. 새 용도는 등록 후 선택 목록에 추가됩니다. 한 행의 용도는 생성되는 모든 일련번호에 적용되며, 장치만 등록할 때는 용도를 비워두세요.
- 같은 장치의 연속 행은 두 번째 행부터 장치이름을 비워도 바로 위 장치를 이어받습니다. 등록 그룹은 가져오기 창 오른쪽 트리에서 선택합니다.
- 일련번호가 있는 행의 위치·설명·태그는 각 개별 장비에 저장됩니다. 일련번호가 없는 행에서는 장치 자체에 저장됩니다. 태그는 `#주력 #비행`처럼 공백으로 구분하며 `#`를 생략해도 자동으로 붙습니다.
- 일련번호는 **텍스트**로 입력하세요. `001` 등 앞자리 0을 유지합니다. 수식·날짜·소수 일련번호, 접두어 불일치, 역순 범위는 오류로 표시합니다.
- 한 범위 최대 10,000개, 한 파일에서 최대 20,000개의 일련번호를 미리 볼 수 있습니다.
- 넓어진 불러오기 창에서 Ctrl/Shift로 행을 선택하고 오른쪽 트리의 그룹으로 드래그하세요. 초록색 영역과 등록 경로로 들어갈 위치를 표시하며, 왼쪽 들여쓰기 영역에 놓으면 상위 그룹에 등록합니다. 오른쪽 **＋ 그룹**으로 선택한 그룹 아래에 새 그룹을 만들 수도 있습니다. 등록 위치를 선택하고 **선택 행 등록**을 눌러도 됩니다. 창은 비모달이어서 메인 화면도 조작할 수 있습니다.
- 엑셀 등록창 오른쪽의 **＋ 장치**로 선택한 그룹 아래에 빈 장치를 먼저 만들 수도 있습니다.
- 같은 위치에 같은 이름의 장치가 있으면 기존 장치에 일련번호를 추가합니다. 중복 일련번호가 포함되면 **선택한 등록 작업 전체를 취소**하고 오류를 표시합니다.
- 입력 오류는 목록에 표시됩니다. 오류가 있는 행을 제외하거나 원본 엑셀을 수정해 다시 불러오세요. 목록의 Delete는 가져오기 후보에서만 제거합니다.
- 불러온 목록의 입력 셀은 더블클릭하거나 F2를 눌러 직접 수정할 수 있습니다. `Ctrl+C`와 `Ctrl+V`로 한 셀 또는 여러 셀을 복사·붙여넣으면 수량과 오류 검사가 즉시 갱신되며, 수정된 값을 그대로 등록합니다.

## 엑셀 장비 목록 조회 및 변경 반영

**도구 → 엑셀 장비 목록 내보내기**로 현재 프로젝트의 모든 장치와 개별 장비를 한 목록으로 저장합니다. 장치 다음에 그 장치의 일련번호를 배치하며, 소속 그룹·장치이름·일련번호·용도·현재 위치·설명·태그·최근 상태를 조회할 수 있습니다. 열 필터와 고정된 머리글을 지원하며, 사용 방법은 파일의 **사용 안내** 시트에도 들어 있습니다. 이 양식은 일련번호 범위를 등록하는 기존 템플릿과 별개입니다.

1. 내보낸 파일의 녹색 열에서 장치이름·일련번호·용도·현재 위치·설명·태그를 수정합니다. 기존 행의 **구분·장비 ID·상위 ID**는 유지하세요. 장치 이름은 장치 행에서 수정하며 개별 장비의 표시 이름에도 함께 반영됩니다. 소속 그룹과 최근 상태는 조회용입니다.
2. 새 일련번호는 같은 장치의 행을 복사한 뒤 **장비 ID(J열)만 비우고** 새 일련번호를 입력합니다. 새 장치는 구분을 **장치**로 적고 장비 ID를 비웁니다. 상위 ID도 비우면 비교 창에서 선택한 그룹에 등록합니다. 새 장치에 일련번호를 추가하려면 구분을 **개별 장비**, 장치이름을 동일하게 적고 장비 ID와 상위 ID를 비우세요. 같은 이름의 상위 장치가 여러 개라면 기존 장치의 상위 ID를 사용해야 합니다.
3. **도구 → 엑셀 장비 목록 비교·반영**에서 수정한 파일을 엽니다. 추가·수정할 장비 수와 각 속성의 현재 값·엑셀 값을 확인하고 **적용 날짜**를 선택합니다. 이 단계에서는 프로젝트를 수정하지 않습니다.
4. **변경사항 반영**을 누르면 자동 백업 후 변경된 장비를 한 번에 저장하며, 추가 및 속성별 변경 기록을 선택한 날짜로 남깁니다. 용도 등 기본 속성은 반영 즉시 바뀌고, 현재 위치는 오늘까지의 가장 최근 위치 기록을 기준으로 표시합니다. 과거 날짜로 입력한 위치보다 더 나중의 위치 기록이 있다면 그 기록의 위치가 현재 위치로 유지됩니다.

파일에서 빠진 장비는 삭제하지 않습니다. 다른 프로젝트의 파일, 중복 일련번호, 잘못된 상위 ID, 수식 등 오류가 있으면 반영을 막습니다. 비교 후 장비 정보가 달라진 경우 다시 비교해야 하며, 반영 중 오류가 나면 해당 작업 전체를 취소합니다. 내보낸 양식의 숨겨진 **SEMP 정보** 시트도 유지하세요. 앞자리 0이 있는 일련번호는 텍스트 형식을 유지해야 합니다.

## 저장과 다른 컴퓨터로 이동

```text
선택한 저장 위치/
└─ 프로젝트 이름/
   ├─ project.semp          프로젝트 이름과 형식 버전
   ├─ data/
   │  └─ semp.sqlite3      장비·이력·기록·서식·태그·휴지통
   └─ backups/             Ctrl+S로 생성한 데이터베이스 백업
```

정보/메모 편집창에서 저장하면 즉시 데이터베이스에 반영됩니다. 트리 이동, 등록, 연결/해제도 즉시 저장됩니다. 작성 중인 편집창에서 취소하면 그 편집 내용은 저장되지 않습니다.

**프로젝트를 닫고 폴더 전체를 옮긴 뒤**, 다른 PC의 SEMP에서 `project.semp`를 열면 됩니다. 프로젝트 데이터에 컴퓨터별 절대 경로를 저장하지 않습니다. 백업은 프로젝트 내부에 쌓이므로 외부 백업이 필요하면 프로젝트 폴더를 별도로 복사하세요.

백업을 복구하려면 프로그램을 닫고 원래 `data/semp.sqlite3`를 별도 보관한 뒤 선택한 `backups/*.sqlite3`를 `data/semp.sqlite3`로 복사합니다. 현재는 수동 복구 방식입니다.

단일 사용자용 프로젝트입니다. 같은 프로젝트를 여러 SEMP에서 동시에 편집하지 못하도록 잠금 파일을 사용합니다. 네트워크 공유나 클라우드 동기화 중 동시 편집은 지원하지 않습니다.

## 기본 조작

| 조작 | 기능 |
|---|---|
| Ctrl+클릭 / Shift+클릭 | 다중 선택 / 연속 선택 |
| Ctrl+A | 활성 목록 전체 선택 |
| 드래그 | 트리 이동, 기록 연결, 엑셀 등록 |
| Ctrl+D | 선택한 그룹·장치와 하위 항목 복제 |
| F2 | 트리/하위 항목의 기본 정보 수정 |
| Delete | 장비·이력은 휴지통, 기록 대상은 연결 해제 |
| 더블클릭 | 기록·하위 장비 상세 탭 열기 |
| Ctrl+Z / Ctrl+Y | 트리에 초점이 있을 때 소속 이동 취소 / 다시 실행 |
| Ctrl+N / Ctrl+O | 프로젝트 생성 / 열기 |
| Ctrl+S | 데이터베이스 백업 |
| Ctrl+F | 통합 검색창으로 이동 |
| Ctrl+B / Ctrl+I / Ctrl+U | 메모 굵게 / 기울임 / 밑줄 |

휴지통은 재실행 후에도 유지됩니다. 삭제한 상위 항목이 필요하면 복원 시 함께 복원합니다. 동일 이름/일련번호 충돌이 있으면 복원 전체를 취소합니다.

## 개발 및 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

실행 코드는 `SEMP.py` 한 파일에 통합되어 있습니다. 파일 안에서 저장·디자인·아이콘·엑셀·위젯·입력창·메인 화면을 구역으로 나누었으며, 테스트는 `tests` 폴더에 별도로 유지합니다. Python과 외부 라이브러리는 기존처럼 설치해야 하며, 엑셀 템플릿과 프로젝트 데이터는 별도 파일로 유지합니다. Qt 테스트는 실제 위젯에 마우스·키보드·드롭 동작을 전달하며 `.qa`에 검토용 화면을 생성합니다. 테스트용 예시 프로젝트는 임시 폴더에만 생성합니다.

Qt 위젯 동작은 [Qt for Python 공식 문서](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTreeWidget.html)를 참고했습니다. PySide6/Qt를 배포할 때는 해당 라이브러리의 라이선스 조건을 확인하세요.
